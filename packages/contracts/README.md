# ArtFi contracts

Solidity contracts enter implementation in Stage 2. This package will contain:

- RWA asset and factory contracts
- Vault and vault factory contracts
- Fractional token contracts
- Governance and timelock contracts
- Deployment manifests and generated ABIs
- Unit, fuzz, invariant, integration, and fork tests

No inherited Sepolia address is treated as authoritative until source, deployment transaction, constructor arguments, roles, and bytecode are verified.
