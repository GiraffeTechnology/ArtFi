# ArtFi agent instructions

- Follow `docs/ROADMAP.md` and link changes to IDs in `docs/PRD_TRACEABILITY.md`.
- Do not enable mainnet, real assets, or real-money operation without a separate written approval.
- Do not add private keys, seed phrases, credentials, database dumps, or signed transactions.
- Treat inherited screenshots and PRD claims as references, not proof of implementation.
- Keep external-wallet integration separate from the Stage 5 custom wallet extension.
- Before handoff, run the checks in `CONTRIBUTING.md` that apply to the changed area.
