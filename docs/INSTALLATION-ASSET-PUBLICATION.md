# Installation asset publication

Publish only verified product artifacts with English release descriptions, their exact source identity and SHA-256 checksums. Preserve original artifact bytes and label component-only distributions accurately. Verify the complete uploaded download and checksum files before marking publication complete.

Private handoff packages, server configurations, account information, keys, tenant-private data, authentication state and production backups are excluded from public publication. An admitted deployment package is not automatically a public-safe installation asset.

Public accessibility and source attribution do not themselves grant usage permission; consult the applicable license and retained notices.

ERC-8415 and erc8415-kit retain their existing licenses. Preserve all required third-party code, component and font license/copyright notices and valid existing rights. Publication must not rewrite Git history.

This publication policy does not add a delivery gate or suspend development, deployment or acceptance. Pull requests may be merged only after their exact required CI checks are all successful. Publication, source merge and CI are separate from actual production and runtime acceptance.
