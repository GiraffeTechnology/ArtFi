## 3. Why no stage can be declared delivered from here

Two reasons, neither of which is a technical question and neither of which an agent may resolve on its
own authority.

**§6.2 condition 2 has no baseline to run against.** G1 (§4) asks for desktop and mobile screenshots
beside `pics/*.png` and `fractional_steps/*`, with human sign-off. Those images have never existed in
this repository. That is M3.10, the single `BLOCKED` row, and `PRD.md` §3.2.4 states plainly that it is
a missing artefact rather than a pending decision, that no reading of any document produces a
screenshot, and that **whether the Figma work replaces that baseline is a client decision an agent
must not assume**.

**Nothing has been exercised at runtime.** No contract is deployed on Hoodi from this branch, no
mirror has connected to a live provider, and no settlement, mint, proposal or holder download has a
transaction hash and receipt. `ACCEPTANCE.md` §3 rules out a public page that renders but cannot
execute its function, and rules out substituting or inferring evidence. This side has no chain access
and no reachable provider, so this is a missing input plus a run, not an analysis anyone can finish by
reading further.

A third, narrower one: **CI has not executed since 2026-09-19.** The last successful run is `246`;
every run since — including `307` on `main` and a re-run of `306` — ends within about five seconds
with no runner assigned and no steps recorded. `ACCEPTANCE.md` §3 accepts a CI run as evidence, so
while this holds, a whole class of evidence is unavailable and local gates are all there is.
