# Whole-receipt Oracle attestation boundary

## Public interface behavior

The reader checks the expected attestation subject, canonical source-record commitment, validity and revocation. Asset identity includes chain, contract and token identity. A certificate locator or hash does not substitute for the canonical source-record commitment.

Private participants, grants and execution references are not sent for verification. Reads are bounded and redirects are refused. A verified observation does not by itself authorize payment or registration.
