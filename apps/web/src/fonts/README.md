# Recovery UI font

The approved ArtCCH:ArtFi Figma marketplace frame (`O9etbeZZD0VrsU8ch9PaZZ`,
`14:38`) specifies Inter for body copy and controls. The recovery panel embeds
the original Inter variable font to avoid depending on system-installed fonts.
Its font class is scoped to this panel; the existing wallet-button style supplies
the established control shape and dimensions.
